# PVDW-Work
## Nick Holmes and Gavin Rinke

This repository concerns Ahmed, Kullmann, and Snevily's publication _On the van der Waerden numbers w(2;3,t)_ (2014).  Within our SageMath worksheet, we corroborate their values for the palindromic van der Waerden numbers pdw(2;3,t).  We use our own techniques to verify the values and compare our runtime to the SAT solver used by the publishers.  

Previewing the code here will show all necessary verifications; the code can also be downloaded and ran through any SageMath compiler.

No new results with respect to these palindromic van der Waerden numbers were found through our AI assisted literature search.
